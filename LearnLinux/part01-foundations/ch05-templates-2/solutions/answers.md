# 第 5 章 练习参考答案

## 练习 1

- `Box<double>` → **主模板**。double 不是指针，没有任何特化匹配它。
- `Box<double*>` → **偏特化** `Box<T*>`，此时 T=double。"装的是指针"成立。
- `Box<const char*>` → **偏特化**，此时 T=const char。关键在看模式：`const char*` 整体是一个指针类型（指向 const char 的指针），与 `T*` 模式把 T 对上 const char，严丝合缝。容易错答成"它带 const 所以走主模板"——const 修饰的是所指的字符，不是这个指针模式本身。

记忆法：偏特化比的是**形状**（是不是指针、是不是引用、是不是数组），形状对上了就按形状里剩下的部分定 T。

## 练习 2

按三步套路：

1. 第一条 error 在第 3 行（调用/实例化处）：`wrong number of template arguments (1, should be 2)`——模板实参个数不对，给了 1 个、需要 2 个。
2. note 在第 2 行指出模板的声明长什么样：`template<class T, int N>`，两个参数一个都不能少（N 没有默认值）。
3. 改法：把非类型参数补上，如 `FixedArray<int, 8> fa;`。若想让 N 可以省略，就得在声明处给默认值（如 `int N = 8`），那是另一回事。

## 练习 3

见 `ex03_int_specialization.cpp`（已编译验证，输出依次为 integer、generic type、C string）。

要点：三个版本（主模板 + 两个全特化）并存，特化之间互不影响；给 int 写的特化只接管 int。注意特化要写在主模板之后、使用之前。

## 练习 4

见 `ex04_sum_all.cpp`（已编译验证，输出 10、7、0）。

要点：终点是一个**普通函数** `int sumAll()` 返回 0；模板每次剥一个参数递归。本版限定元素同为 int——若混入 double，返回值类型与截断问题就会冒出来，那正是 C++17 折叠表达式 + 返回类型推导要解决的，专题章见。

## 练习 5

通行解法是**用重载代替偏特化**：再写一个参数为 `T*` 的同名重载版本。调用时编译器走第 4 章的决议规则：普通实参命中通用版，指针实参会精确匹配 `T*` 版本——效果与"偏特化"等价，还避开了全特化不参与重载决议的坑。

```cpp
template <typename T> void handle(T v)  { /* 通用版 */ }
template <typename T> void handle(T* p) { /* 指针版：相当于"偏特化" */ }
```

另一条路是把函数转发给一个类模板的静态成员，借类模板的偏特化来分流——库代码里能见到，但日常优先用重载，简单直接。
