## 练习 1（读代码，写输出）

下面这段程序的输出是什么？先纸面推演，再上机验证。

```cpp
#include <cstdio>
int main() {
    int x = 5, y = 9;
    int* p = &x;
    *p = *p + 2;
    p = &y;
    *p = 1;
    std::printf("x=%d, y=%d\n", x, y);
    return 0;
}
```

提示：`p = &y` 改的是指针的"指向"，不是任何变量的值。
