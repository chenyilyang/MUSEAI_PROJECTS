# 第 1 章 练习参考答案

## 练习 1

输出：`x=7, y=1`

推演：`p` 先指向 `x`，`*p = *p + 2` 把 `x` 改成 7；然后 `p = &y` 让 `p` 改指向 `y`（这一步只动指针本身，不动任何变量的值）；`*p = 1` 把 `y` 改成 1。所以 `x` 保持 7，`y` 变成 1。最常见的错答是以为 `p = &y` 会把 `x` 也怎么样——不会，指向和值是两回事。

## 练习 2

问题：`int* p;` 只声明了指针、没有给它赋初值，`p` 里是一个随机地址（野指针），紧接着 `*p = 10` 就是往这个随机地址写数据——未定义行为：可能当场崩溃（段错误），也可能悄悄破坏别处的数据、当时看不出任何异常。后一种更危险。

改法（本章范围内）：先让指针指向一个真实存在的变量再使用：

```cpp
int v = 0;
int* p = &v;
*p = 10;
```

记住习惯：**声明指针时立刻初始化**；暂时没有指向就用 `nullptr`（第 2 章细讲）。指向不明就解引用，是 C/C++ 里最经典的事故来源。

## 练习 3

见 `ex03_add_ten.cpp`（已编译验证，输出 before: 80 / after: 90）。

要点：调用处传的是 `&speed`（地址），函数里用 `*p` 改到的是 `speed` 本身。这正是"函数想改外面的变量，就把地址交出去"。

## 练习 4

见 `ex04_max_by_pointer.cpp`（已编译验证，输出 max = 21）。

要点：用尾后指针 `arr + 5` 做循环边界，当前最大值也先经 `*arr` 取首元素；全程没有下标。

## 练习 5

指针变量里存的只是一个地址编号，它的大小只由机器的地址位数决定（64 位机就是 8 字节），与指向什么无关。而 `p + 1` 的步长是"一个元素的大小"，由所指类型的 `sizeof` 决定：`int` 是 4 字节，`char` 是 1 字节。一句话：**大小看地址位数，步长看所指类型**。
