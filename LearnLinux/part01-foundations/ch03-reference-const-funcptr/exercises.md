## 练习 1（读代码，写输出）

```cpp
#include <cstdio>
int main() {
    int a = 5;
    int& r = a;
    int b = 8;
    r = b;
    ++r;
    std::printf("a=%d, b=%d\n", a, b);
    return 0;
}
```

输出是什么？特别注意 `r = b;` 这一行到底做了什么。

## 练习 2（找错误，两处）

下面两段各自有一处 const 相关的错误，指出错误并说明编译器为什么拦它、应该怎么改：

```cpp
// 片段 A
const int limit = 100;
int* p = &limit;
*p = 200;
```

```cpp
// 片段 B
int x = 1, z = 3;
int* const cp = &x;
cp = &z;
```

## 练习 3（写代码）

写函数 `void clampValue(int& v, int lo, int hi)`：把 `v` 钳制在 `[lo, hi]` 内——小于 `lo` 改成 `lo`，大于 `hi` 改成 `hi`。在 `main` 里验证：150 → 100、-5 → 0、42 → 42（区间 `[0, 100]`）。

要求：用引用传参（想想为什么不用指针、不用按值）。

## 练习 4（写代码）

写函数 `void transform(int* arr, int n, int (*fn)(int))`：对数组每个元素调用 `fn` 并用返回值替换它。再写两个回调 `square`（平方）和 `negate`（取负），验证：

- `{1, 2, 3, 4}` 经 `square` 后是 `1 4 9 16`；
- 另一份 `{1, 2, 3, 4}` 经 `negate` 后是 `-1 -2 -3 -4`。

## 练习 5（思考题）

给函数参数选型时，面对下面四种情况你分别选什么（按值 / `T*` / `T&` / `const T&`），各用一句话说理由：

1. 函数要修改调用者的一个 int，且该 int 必然存在；
2. 函数只读取一个很大的结构体（如一帧 CAN 报文的解析结果），绝不修改；
3. 函数的参数可以"没有"（调用者可能传空表示无数据），函数内部要遍历一段数组；
4. 函数只读取一个 double 做计算。
