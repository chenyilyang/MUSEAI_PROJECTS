## 练习 2（死锁四条件 + 锁排序设计）

1. 这组顺序是否构成死锁风险？用四条件逐条对号，并画出等待环。
2. 给一个全局锁顺序方案，并说明甲乙丙各需要怎样改（或不改）。

## 练习 4（写代码：修到 TSan 干净）

下面这段词频统计是坏的（先想它坏在哪、坏到什么程度）:

```cpp
static std::map<std::string, int> g_counts;   // 4 个线程并发执行下面函数
void countWords() {
    const char* words[4] = {"can", "hal", "someip", "vsomeip"};
    for (int r = 0; r < 250; ++r)
        for (int w = 0; w < 4; ++w)
            ++g_counts[words[w]];
}
```

把它改成线程安全版：4 线程跑完后每词恰为 1000、总数 4000。再以 TSan 构建运行你的版本验证零报告，并去掉锁重跑一次，确认 TSan 会报——正反各留一手证据。
