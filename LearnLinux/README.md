# LearnLinux —— Linux C++ 开发教程（面向智能座舱）

一套为智能座舱开发岗位定制的 Linux C++ 教程：从补齐指针、模板地基开始，
一路走到多线程并发、网络与共享内存，再进入车载专题
（SocketCAN、SOME/IP + vsomeip、Fast DDS、Vehicle HAL 模拟），
最后完成毕业项目"座舱信号网关"。

- 设计文档：[docs/2026-10-22-linux-cpp-tutorial-design.md](docs/2026-10-22-linux-cpp-tutorial-design.md)
- 学习方式：按部分分批更新，学完一批反馈一次，后续章节据此调整深浅。
- 环境基线：Ubuntu 24.04 + GCC 13 + CMake。
