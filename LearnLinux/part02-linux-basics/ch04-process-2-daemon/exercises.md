## 练习 2（读代码：三个隐患）

一份"守护进程"代码有三个隐患：

```cpp
int main() {
    if (setsid() < 0) return 1;          // (1) 直接 setsid，没先 fork
    chdir("/tmp/workdir");               // 工作目录停在某个工作区
    int log = open("daemon.log", O_WRONLY | O_CREAT | O_APPEND, 0644);
    // (2) 没动标准流：0/1/2 还连着启动时的终端
    for (;;) {
        // (3) 出问题时用 printf 打印错误信息，想着"反正能看见"
        doWork();
        sleep(1);
    }
}
```

逐个说清隐患的后果：(1) 这行在什么情况下直接失败？(2) 标准流还连着终端会带来哪些具体麻烦（结合 fd 分配规则想一想）？(3) printf 的输出实际去了哪里、为什么等于没记？
