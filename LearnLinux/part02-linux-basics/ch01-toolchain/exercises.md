## 练习 2（读 ldd 输出）

某程序 `ldd app` 的输出节选：

```
libcalc.so => /opt/app/lib/libcalc.so (0x00007f...)
libstdc++.so.6 => /lib/x86_64-linux-gnu/libstdc++.so.6 (0x00007f...)
libmissing.so => not found
```

回答三件事：（a）哪一行是本工程自产的动态库、哪一行是系统库？（b）第三行意味着程序现在能不能跑、启动时会报什么错？（c）给出两种独立解法的大致思路。

## 练习 4（动手：用 GDB 定位一个新 bug）

保存下面这段代码为 `buggy_avg.cpp`，编译（记得 `-g -O0`）后它输出 `avg = 1`，正确值应为 1.5。用 GDB 按正文的方法定位病根：该在哪一行下断点、print 哪两个量、看到什么数值组合能断定问题不在循环而在最后一步？写出你的定位过程与结论，再修正它。

```cpp
#include <cstdio>
int main() {
    int values[] = {1, 2};
    int n = 2;
    int sum = 0;
    for (int i = 0; i < n; ++i) sum += values[i];
    int avg = sum / n;
    std::printf("avg = %d\n", avg);
    return 0;
}
```
